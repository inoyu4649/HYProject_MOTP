# MOTP v0.6.0 모딩 ID 매핑

이 문서는 v0.6.0의 모딩용 이름표를 고정해 둔 표다. 다음 버전에서 이름표가 바뀌면 이 파일을
고치지 않고 새 버전 파일을 추가한다.

## 그림 논리 ID (`mod.json.assets`)

| 논리 ID | 원본 `res/` 상대 경로 |
|---|---|
| `photo.grad-group-1` | `user/HYHS_88th_grad_group1.png` |
| `photo.grad-group-1-35` | `user/HYHS_88th_grad_group1_35.png` |
| `photo.grad-group-2` | `user/HYHS_88th_grad_group2.png` |
| `photo.festival-2027` | `user/photo_festival_2027.png` |
| `photo.editorial-group` | `user/photo_editorial_group.png` |
| `photo.profile.sje` | `user/profile/302_SJE.png` |
| `photo.film-unofficial.01` … `.07` | `user/film_unofficial_01.png` … `_07.png` |
| `photo.profile.30201` … `photo.profile.30234` | `user/profile/30201.png` … `user/profile/30234.png` |

예:

```json
{
  "assets": {
    "photo.grad-group-1": "res/user/my_group.png",
    "photo.profile.30217": "res/user/profile/my_30217.png"
  }
}
```

논리 ID가 없는 그림도 바꿀 수 있다. 모드의 `res/` 아래에 설치본 `res/`와 **같은 상대 경로**로
파일을 두면 그 경로를 대신 읽는다. 이 경로 방식은 그림과 오디오에 모두 적용된다.

`data/bgm.json` 패치를 쓴다.

## 효과음 ID (`data/sfx.json`)

효과음 ID는 곧 `res/audio/` 상대 경로다.

`sfx/achievement.ogg`, `sfx/press-run.ogg`, `sfx/patrol-caught.ogg`,
`sfx/rollcall-page.ogg`, `sfx/rollcall-named.ogg`, `sfx/void-catch.ogg`,
`sfx/void-appear.ogg`, `sfx/lockers-rattle.ogg`, `sfx/elevator-door.ogg`,
`sfx/elevator-arrive.ogg`, `sfx/shadow-touch.ogg`, `sfx/film-burn.ogg`,
`sfx/dorm-knock.ogg`, `sfx/dorm-key-slide.ogg`, `sfx/dorm-doors-open.ogg`,
`sfx/time-shift.ogg`, `sfx/key-open.ogg`, `sfx/key-reject.ogg`,
`sfx/wire-cut.ogg`, `sfx/wire-connect.ogg`, `sfx/wire-reject.ogg`,
`sfx/tape-play.ogg`, `sfx/typewriter.ogg`, `sfx/ui-hover.ogg`,
`sfx/ui-click.ogg`, `sfx/write.ogg`.

`sfx/rollcall/`은 접두 경로 단위 기본 음량을 가진다. 파일 교체는 같은 경로의 `res/audio/...`를,
음량 변경은 `data/sfx.json`의 `volumes` 또는 `prefixes`를 쓴다.

```json
{
  "fonts": {
    "notoSerifKr": {
      "file": "fonts/my-ui.woff2",
      "family": "My UI",
      "weight": "400 700"
    }
  }
}
```

## 데이터 패치 파일

| 파일 | 대상으로 쓰는 ID |
|---|---|
| `data/items.json` | 소지품 ID |
| `data/objectives.json` | 목표 ID |
| `data/difficulty.json` | 난이도 조율 축 및 난이도 ID |
| `data/achievements.json` | 도전과제 ID |
| `data/flags.json` | 플래그 ID |
| `maps/*.json` | 파일명이 아니라 JSON 안의 맵 `id` |
| `locales/<lang>/<namespace>.json` | i18n 키 |

각 패치 형식과 허용 필드는 상위 문서 [`../MODDING.md`](../MODDING.md)를 따른다.
